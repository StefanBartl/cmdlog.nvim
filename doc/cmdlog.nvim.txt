*cmdlog.nvim.txt*  Interactive command-line history viewer for Neovim

==============================================================================
CMDLOG.NVIM                                            *cmdlog.nvim*

cmdlog.nvim is a lightweight Neovim plugin that provides interactive access
to Neovim command-line (:) history and shell history using a fuzzy picker UI.
It integrates with Telescope.nvim or fzf-lua and allows searching, previewing,
favoriting, and reusing past commands.

This plugin focuses on inspection and reuse of existing history entries.
Commands are inserted into the command-line but are never executed
automatically.

==============================================================================
FEATURES                                               *cmdlog.nvim-features*

- Interactive listing of Neovim command-line (:) history
- Optional integration of shell history (bash, zsh, fish, nu, ksh, csh)
- Picker backend selection:
  - Telescope.nvim (default, with previews)
  - fzf-lua (minimal, fast, no previews yet)
- Favorites system with persistent storage
- Non-destructive command reuse (insert only, no auto-exec)
- Extensible picker infrastructure for custom pickers

==============================================================================
REQUIREMENTS                                           *cmdlog.nvim-requirements*

Required plugins:

- lib.nvim              (required, cross-platform fs/notify helpers)
- telescope.nvim        (required when picker = "telescope")
- fzf-lua               (required when picker = "fzf")
- plenary.nvim          (required for favorites and utilities)

==============================================================================
SETUP                                                  *cmdlog.nvim-setup*

The plugin is configured via a setup() call.

Example:

    lua require("cmdlog").setup({
      picker = "telescope",
    })

Available options:

picker    Picker backend to use.
          Values: "telescope" (default), "fzf"

mappings  Keymaps used inside pickers. Set an entry to `false` to disable
          it, or `mappings.enabled = false` to disable all of them.
            select           (default "<CR>")
            toggle_favorite  (default "<Tab>")
            refresh          (default "<C-r>")
            delete           (default "<C-x>")

          `delete` removes the selected command from its underlying
          history: Neovim's `:` history via histdel() (no prompt), or the
          shell history file (rewritten on disk after a confirm prompt).

keymaps   Optional normal-mode entry-point keymaps for the :Cmdlog*
          commands. Disabled by default (`enabled = false`). Each entry
          you set carries a `desc`, so which-key.nvim shows it
          automatically. See docs/BINDINGS.md in the repository for all
          available keys.

highlight_risky   Highlight commands matching `risky_patterns` (e.g.
                  "rm -rf", "git reset --hard") with the CmdlogRiskyCommand
                  highlight group. Default: true. Telescope-only.

risky_patterns    List of Lua patterns checked against each command when
                  `highlight_risky` is enabled. Set to `{}` to disable.

project_scoped    Opt-in per-project favorites. Disabled by default.
                  `{ enabled = true }` stores favorites in a dedicated file
                  under `<favorites_path dir>/projects/`, named after the
                  Git root detected upward from the current working
                  directory. Outside a Git repo, or when disabled, the
                  global `favorites_path` is used.

==============================================================================
COMMANDS                                               *cmdlog.nvim-commands*

:CmdlogFavorites                                       *:CmdlogFavorites*
    Show only commands marked as favorites.

:Cmdlog                                                *:Cmdlog*
    Show favorites and history combined.
    Only unique commands are shown; duplicates are removed.

:CmdlogFull                                            *:CmdlogFull*
    Show favorites and full history.
    Duplicate commands are allowed.

:CmdlogNvim                                            *:CmdlogNvim*
    Show only Neovim (:) commands.
    Only unique commands are shown; the latest occurrence is kept.

:CmdlogNvimFull                                        *:CmdlogNvimFull*
    Show full Neovim (:) command history, including duplicates.

:CmdlogShell                                           *:CmdlogShell*
    Show shell history entries.
    Only unique commands are shown; the latest occurrence is kept.

:CmdlogShellFull                                       *:CmdlogShellFull*
    Show full shell history, including duplicates.

==============================================================================
PICKER USAGE                                           *cmdlog.nvim-usage*

Inside the picker, the following mappings are available:

<CR>        Insert the selected command into the command-line.
            The command is not executed automatically.

<Tab>       Toggle favorite status for the selected command.

<C-r>       Refresh the picker contents.

<C-x>       Delete the selected command from its underlying history
            (Neovim `:` history or the shell history file). See |cmdlog.nvim-setup|
            for how the shell-history deletion confirmation works.

==============================================================================
COMMAND PREVIEWS                                       *cmdlog.nvim-previews*

When using Telescope.nvim, previews may be available depending on the command:

:edit {file}
    Shows a preview of the file if it is readable.

:!{shell-command}
    Simulates shell command output for supported shells.

:term, :make, :lua, :help
    Preview support is experimental or in progress.

When using fzf-lua, previews are currently not available.

==============================================================================
FAVORITES                                              *cmdlog.nvim-favorites*

Favorites are stored persistently on disk.

Default location:

  ~/.local/share/cmdlog.nvim/favorites.json

On Windows, the path resolves via stdpath("data").

Favorites are shared across all Neovim sessions.

==============================================================================
SHELL HISTORY                                          *cmdlog.nvim-shell*

Shell history is read from standard history files, depending on the shell:

- zsh   ~/.zsh_history
- bash  ~/.bash_history
- fish  ~/.local/share/fish/fish_history
- nu    ~/.config/nushell/history.txt
- ksh   ~/.ksh_history
- csh   ~/.history
- pwsh  %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt

The plugin only reads these files and never modifies them.

==============================================================================
EXTENDING                                              *cmdlog.nvim-extending*

cmdlog.nvim is designed to be extensible.

Utility helpers are provided in picker_utils.lua to simplify the creation
of custom pickers. Custom pickers can reuse sorting, preview, and action
logic without reimplementing common behavior.

See the /docs directory in the repository for developer-oriented guides.

==============================================================================
HEALTH                                                 *cmdlog.nvim-health*

Run `:checkhealth cmdlog` to verify dependencies (plenary.nvim,
telescope.nvim/fzf-lua depending on `picker`), shell-history detection,
and the notes directory.

==============================================================================
NOTES                                                  *cmdlog.nvim-notes*

- cmdlog.nvim relies on Neovim's persisted command-line history (shada).
  Ensure that the 'shada' option includes ':' to enable command history
  persistence.
- Commands are never executed automatically by this plugin.
- Multiple concurrent Neovim instances may affect history ordering.
